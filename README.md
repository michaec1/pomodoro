# 🍅 番茄鐘 Pomodoro Timer

**[▶ 線上預覽](https://michaec1.github.io/pomodoro/pomodoro.html)**

一個簡單好用的番茄工作法計時器，提供網頁版與 Python 桌面版。

## 功能

- 工作／短休／長休三種模式，4 個番茄自動切換長休
- 環形倒數進度條，即時顯示剩餘時間
- 完成提示音與桌面通知
- 輪次追蹤（● 圓點顯示本輪進度）
- 可自訂各模式時間（1–120 分鐘）
- 開始、暫停、重置、跳過

## 使用方式

### 網頁版 `pomodoro.html`

直接用瀏覽器開啟，無需安裝任何套件。

| 快捷鍵 | 功能 |
|--------|------|
| `Space` | 開始 / 暫停 |
| `R` | 重置 |
| `S` | 跳過 |

### Python 桌面版 `pomodoro.py`

需要 Python 3.x（內建 tkinter，無需額外安裝）：

```bash
python pomodoro.py
```

> 僅支援 Windows（使用 `winsound` 播放提示音）

## 預設時間

| 模式 | 時間 |
|------|------|
| 工作時間 | 25 分鐘 |
| 短暫休息 | 5 分鐘 |
| 長休息 | 15 分鐘 |
